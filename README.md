# coin_auto
BTC 급락 매수 봇 — OKX USDT 무기한 선물 (격리 마진, 롱 전용, 1배)

2026-09-27 전략 교체. 옛 '일봉 국면 + 4h 돌파' 봇과 그 연구 전부는 커밋 `d29f29f` 에 보존돼 있다.

규칙 (strategy.py 한 곳에만 있다):
- 진입: 완성된 5분봉 종가가 1시간 지수이평(5분봉 12개) 대비 **−2% 이하** & 전날 일봉 종가가 **50일선·200일선 둘 다 위** → 롱
- 청산: 진입가 **+4% 익절 / −6% 손절 / 3일 만기**. 한 봉에서 둘 다 닿으면 손절로 본다
- 숏 없음 — 급등 받아치기 숏 216조합 전부 실패 (research/aoa/short.py)
- 5분봉 마감 15초 뒤마다 판단. 꺼져 있던 동안의 봉은 청산 확인만 따라잡고, 지난 신호로 뒤늦게 사지 않는다

근거 (research_aoa.txt — 워뇨띠 BitMEX 체결 94만 건 분석에서 출발):
- 그의 방향 결정은 "1시간 단위 역추세" (정확도 ~70%). 그대로 베끼면 손실, 급락 롱만 떼어 익절·손절을 붙이면 양수
- 1배 백테스트 (비용 0.07%·펀딩 포함, strategy 규칙 그대로 재생):

  | 데이터 | 승률 | 거래당 | 연복리 | MDD |
  |---|---|---|---|---|
  | OKX 2021-05~2026-09 | 75% | +1.49% | +8.7% | −13% |
  | 바이낸스 2020-03~2026-09 | 75% | +1.47% | +20.0% | −16% |
  | BitMEX 2018-03~2021-12 | 66% | +0.85% | +27.9% | −37% |

- 처음 보는 알트 6종에서도 급락 매수·50일선 필터가 재현됐다 (사전등록). 2배는 BitMEX MDD −63% 로 불합격 → 1배

```
make run        포트 정리 후 대시보드+봇 실행 (http://localhost:8000)
make bot        대시보드 없이 터미널 봇만
make stop       포트 8000 프로세스 종료
make on/off     자동실행 켜기/끄기 (실행 중에도 즉시 반영)
make once       판단 1회만
make test       자체 점검 (거래소 공개 API 포함)
make offline    거래소 없이 점검 (상태기계 · 청산선 · 백테스트 재생 대조)
make replay     1배/2배 성적표 재측정
make keys       API 키 확인 (주문 없음)
make reset      모의 장부 초기화
```
사이징: 명목 = 자산 × POSITION_PCT × LEVERAGE × (1 − CASH_RESERVE). 레버리지 코드 상한 2배.
안전장치 (2026-09-10 감사에서 고친 것 그대로): 주문 의도를 먼저 기록 → 제출 → clOrdId 재조회 → 그 체결값으로 장부 확정,
타임아웃은 '불명' 으로 남기고 다음 사이클에 거래소 상태로 대사, 주문 가능한 프로세스는 하나(포트 락),
24시간 고점 대비 −15%(MAX_DAY_LOSS_PCT)면 청산 후 신규 진입 정지 (재개 `make on`).
Claude 검토: 주문 직전에만 OmniRoute(http://localhost:20128) 경유로 호출해 알고리즘 값을 대조·거부한다 (instructions.md).
모의 3단계: 모의 장부(MODE=paper, 지금) → OKX 데모(MODE=live, OKX_DEMO=1) → 실계좌(OKX_DEMO=0). 설정은 .env.example.
실계좌 전 할 일: 실주문 청산은 5분봉 마감 뒤 시장가라 최대 5분 늦다 — 거래소 TP/SL 주문 부착을 검토할 것.
최소 주문 10 USDT — 1배면 잔고가 10 USDT 이상이어야 주문이 나간다.
