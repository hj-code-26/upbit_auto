# RLS-C v1 자동매매 (OKX 한 계좌 · 격리 30x · BTC/ETH 시각 분할 6몫 · 종목당 증거금 4%)

주식 슬리브(OKX 주식 USDT 무기한, NDX M5 상위 5 중 확정 BULL 롱) + 코인 슬리브(BTC·ETH 확정 BULL 롱 / BEAR 숏).
CONF3 레짐, 손절(청산가 안쪽 cap), BE1, DROP1(일봉), edge 재진입 제한, 증거금 = 실현 잔고 2%, 동시 합 ≤ 전일 자산 10%.
**C 규칙 (2026-10-12, `RLS-C2`)**: 본전(BE1) 뒤 손절은 edge 를 걸지 않고, 신호 봉 ATR14/종가 > 8% 면 진입하지 않고 기다린다 (`rls.edge_after`, `rls.vol_ok`).
ETH 3몫 4% 리플레이: 2020-04~ CAGR 42.2% · MDD 19.8% · Sharpe 1.59 (C1 32.6% · 19.8% · 1.38), 2025-01~ +106% (C1 +71%). 같은 데이터로 고른 규칙이다.

**과거 백테스트(2020-04-01~2026-10-09, 일봉 근사)의 사후 탐색 결과이며 수익을 보장하지 않는다.**
명세 수치(**주식+코인 한 계좌 — 지금 운용(코인만)과 다른 구성**): CAGR 45.2% · MDD −21.4% · Sharpe 1.44 · 거래 329 (주식 211, 코인 118) · 승률 27.4% · PF 2.30. 코인 운용 성과로 쓰지 않는다.

**2026-10-16 사용자 결정 (위험을 더 지고 수익을 키움): 3몫·2% → 6몫(UTC 00·04·08·12·16·20)·종목당 4%.**
몫당 명목은 예전과 같다 (4%/6 × 30 = 자산의 20%) → 최소 자금도 같다. 리플레이 `c6-l30-m4.0` (2020-04-01~2026-10-15):
CAGR 60.5% · MDD 27.2% · Sharpe 1.72 · 최악 달 −12.2% / 최근 3년(2023-10-16~) 누적 +572% · MDD 27.2%.
(같은 수정 리플레이로 예전 3몫·2%: 34.9% · 21.1% · 1.67 / 3년 +203%.) 안 본 코인 SOL+XRP 에서는 이 크기가 −35% 정지에 걸렸다 — 이 수치도 같은 데이터로 고른 것이다.
몫 구성을 바꿀 때는 열린 몫이 없어야 한다 (`autotrade.tranche_guard`, 배포 점검이 막는다). 근거: `reports/research_2026-10-16/`.
**C3 (2026-10-16 사용자 결정): 확정 레짐이 NEUTRAL 이면 ADX14 > 30 인 DI 방향이 3일 연속일 때 그 방향으로 (코인만, `rls.adx_dir`).**
리플레이 2020-04~2026-10-15: BTC+ETH 6몫 4% `c6-l30-m4.0` CAGR 60.5% · MDD 28.4% · Sharpe 1.69 (C2 60.5% · 27.2% · 1.72), 3년 +670% (C2 +572%) /
서버 구성 ETH 3몫 4% `e3-l30-m4.0` 44.1% · 23.1% · 1.59 (C2 42.3% · 21.2% · 1.56), 3년 +330% (C2 +286%). BTC·ETH 는 거의 같고 SOL+XRP 에서 개선 — 같은 데이터로 고른 규칙이다.
**동적 크기 (2026-10-17 사용자 결정, `rls.vol_k`, `RLSC_VOL_TARGET`, 기본 0.04, 0 = 끔): 진입 증거금 × clip(4% / 신호 봉 ATR%, 0.5, 2).**
거래소 레버리지는 30x 그대로, 변동성이 크면 포지션을 줄이고 작으면 키운다 (같은 방향 몫이 한 포지션을 공유해 거래마다 레버리지를 바꾸지 않는다).
리플레이 2020-04~2026-10-15: 서버 구성 ETH 3몫 4% `e3-l30-m4.0` CAGR 46.7% · MDD 23.2% · Sharpe 1.72 (고정 44.1% · 23.1% · 1.59), 3년 +365% (고정 +330%) /
ETH 3몫 5% `e3-l30-m5.0` 52.4% · 23.3% · 1.69, 3년 +448%. **BTC+ETH 6몫 4% 는 나빠진다** (`c6-l30-m4.0` 51.5% · 33.9% · 1.54, 고정 60.5% · 28.4% · 1.69) → BTC 를 다시 넣으면 `RLSC_VOL_TARGET=0`.
기간별 분포 (ETH 3몫, `riskprofile.csv`): 30일 수익 중앙 0% · 손실 창 약 45%, 90일 손실 창 약 35%, 365일 손실 창 8~13%.
아래 표·설명의 3몫·2% 수치는 이전 기준이다.

**운용: 코인 슬리브(BTC·ETH) 시각 분할 (기본 6몫, `RLSC_TRANCHES=0` 이면 1몫).** 서버 배포 유닛은 1몫이라는 기록이 있으나 미확인 — 실제 값은 `systemctl show rlsc-autotrade -p Environment`. 자본을 3등분해 몫마다 다른 일봉 경계(UTC 00·08·16 = KST 09·17·01)로
같은 규칙을 하루 1번 돌린다. 몫마다 진입가·손절·본전·DROP1·edge 가 따로 있고, 손절도 몫 수량만큼 따로 건다.
**OKX 계정을 long/short(헤지) 포지션 모드로 둬야 한다** (몫끼리 방향이 달라도 상쇄되지 않게). 포지션이 없을 때만 바꿀 수 있다.
**레버리지 30x** (2026-10-11 사용자 결정, 명세 20x 에서 변경). 손절 상한 = 1/30 − 티어1 MMR − taker − 1%p ≈ 1.88%.
몫당 증거금 = 실현 잔고 2%/3 → 명목 = 자산의 20%. BTC 까지 거래하려면 자산 약 42 USDT, ETH 는 약 13 USDT 이상.

`RLSC_MARGIN` 을 `0.83 / 잔고(USDT)` 이상으로 올리거나 (위험도 같은 비율로 커짐), 2% 로 두고 ETH 만 거래한다 (BTC 는 자동으로 건너뜀).
`python autotrade.py --preflight` 가 지금 잔고로 필요한 비율을 계산한다. 약 17 USDT 미만은 5% 상한 안에서 BTC 불가.

| `stocks.py` | 주식 슬리브 리플레이용 데이터 (운용 작업은 없음) |

사용자가 넣는 파일:
- `ndx_members.csv` — `date,ticker` 구성종목 스냅샷 (yfinance 티커 표기, 예: `BRK-B`). 다음 스냅샷 전까지 유효. 운용은 마지막 스냅샷.
- `corporate_events.csv` (선택) — `date,ticker,type` 분할·병합·특별배당·상장폐지 일정. 자동 보충: 구성종목 편출, OKX 공지 제목, yfinance 분할.

```bash
pip install -r requirements.txt
python test_bot.py
python backtest.py                 # ndx_members.csv 필요
python autotrade.py --job t0       # MODE=dry 기본. 또는 인자 없이 스케줄 루프 / python dashboard.py
```

처음 실행 때 몫마다 과거 일봉 리플레이로 edge 상태를 복원한다.

위험 한도 (위험 정책 R2, 위험 감시가 기본 5초마다): UTC 날 경계 기준 대비 −5% → 전 몫 즉시 청산·그 UTC 날 진입 없음 (다음 날 그 사유만 해제) /
일별 고점 대비 −35% → 상시 판정, 즉시 계좌 단위 전량 청산·정지 / 강제청산 1건·몫별 20연패 → 진입 중단 (`python autotrade.py --resume`).
조회 실패·수량 불일치·미보호 몫·봇 외 주문·미확정 주문 → 신규 진입 차단 (원인이 사라지면 자동 해제). 상태: RUNNING → HALTING → FLATTENING → HALTED / DEGRADED.
−5%·−35% 는 발동 기준이지 손실 상한이 아니다 (갭·API 장애 때 더 잃을 수 있다). 입출금은 기준·고점을 같은 금액만큼 옮긴다.

순서: dry 2주 → `MODE=demo` 4주 이상 (청산가가 OKX 공식·티어와 맞는지 확인) → `MODE=live` 소액.
