# RLS-C v1 검증 보고서 (2026-10-11)

> 과거 리플레이(사후 탐색으로 고른 설정)와 로컬 모의 테스트 결과다. 수익을 보장하지 않는다. 서버·거래소 계정에는 접근하지 않았다.

## 1. 확인 결과

주장별 근거는 `reports/rlsc_gap_audit.md`. 핵심만:

- **확인되어 고친 문제**: 킬 감지 후 청산이 다음 몫 작업(1몫이면 최대 약 24시간)까지 미뤄짐 · 위험 감시가 매시 1번 · 비상 청산이 몫 단위 주문 + 손절 선취소 · 부분 체결 수량 장부 누락 · 응답 유실 주문을 다음 실행에서 확정하는 경로 없음 · 손절 접수만으로 보호 간주 · tick 반올림이 청산가 쪽으로 밀 수 있음 · 현재가를 넘은 손절 검사 없음 · 수동·타 봇 조건부 주문까지 고아로 취소 · 수량 불일치에도 진입 계속 · 중단 사유 덮어쓰기 · 운용 킬 35% vs 리플레이 40% · 위험 자산 범위(totalEq USD) · 입출금 미처리 · `.env.example` net 안내 · 1몫 30x 성과 미제시 · 테스트가 운용 로그에 가짜 주문 기록 · hub 가 새 상태에서 "정상"으로 보일 수 있음 · 슬리피지로 몫 증거금 2%/N 초과 가능.
- **재현 안 됨**: 00:02 자산 저장 후 같은 값을 분모로 쓰는 문제 (판정 뒤에 덮어씀 — 정상).
- **확인 불가**: 서버의 실제 MODE·RLSC_TRANCHES·레버리지, 거래소 적용값, OKX 헤지 모드의 과대 청산 주문 처리 방식.

| run | c1-l30 CAGR / MDD | c3-l30 CAGR / MDD |
|---|---|---|
| 기준 (편도 2bp, 펀딩 0.01%/8h 부호대로) | 14.9 / 22.0 | 27.3 / 18.9 |
| 편도 +5bp | 14.2 / 22.8 | 25.8 / 19.6 |
| 편도 +10bp | 13.5 / 23.7 | 25.0 / 20.0 |
| 편도 +20bp | 12.0 / 25.3 | 22.5 / 23.9 |
| 펀딩 2배 (지급·수취 모두 2배 — 항상 보수적이진 않음) | 14.2 / 21.9 | 26.1 / 19.1 |
| 불리 펀딩 (롱·숏 모두 |0.03%/일| 지급) | 13.7 / 24.4 | 25.9 / 19.3 |
| 기존 문서 스트레스 (편도 10bp + 펀딩 2배) | 13.0 / 22.5 | 24.1 / 20.0 |

bp 는 체결가 대비 가격 차이, 진입·청산 각각 적용 (편도). 수수료 taker 0.05% 는 별도. 고정 운영비는 넣지 않았다 — 최소 주문 자금(1몫 30x: BTC 실현 잔고 약 14 USDT, 3몫 약 42 USDT)에서는 월 서버비 몇 달러가 연 수익을 넘을 수 있다.

**1H 손절 체결 진단** (`stop_fill_1h`): c1-l30 손절 88건 중 시간 봉 사이 갭으로 손절가를 건너뛴 경우 0건 (일봉 근사의 손절가 체결이 1H 기준으로는 낙관적이지 않음). 단 17건(19%)은 손절을 넘은 그 시간 봉 안에서 가격이 청산가 수준까지 갔다 — mark/last 경로와 시장가 체결 속도에 따라 실제 손실이 손절 손실(종목당 약 1.13% E)보다 클 수 있고, 강제청산 안전성은 검증되지 않았다 (mark 자료 없음, last=mark 가정).

**리플레이·운용 차이** (manifest `assumptions`): 몫 경계 시가 체결 vs 운용 HH:02 시장가 (1분봉 없음), 몫마다 독립 일손실·킬 vs 운용 계좌 합산 (3몫 일손실을 몫별로 끈 run 27.2/18.6 → 영향 작음), 20연패·강제청산 진입 중단과 사람 재개 미반영, 펀딩 고정률 (과거 실제 펀딩은 3개월치만 제공), 티어1 MMR 0.4% 고정, 몫별 독립 복리 (운용은 매 진입 시 계좌 실현 잔고/N).

### 5.4 과적합·선택 편향

- 실험 이력 (git): `4737945` 2026-10-06 10x → `e981f63` 2026-10-09 20x·4%·DROP1 → 작업 트리 2026-10-11 30x·2%·3몫. 모두 2020-04~2026-10 전 구간을 본 뒤 정했다. SMA·CONF3·BE1·DROP1·몫 경계·20연패를 언제 무엇을 보고 정했는지는 저장소에 기록이 없다.

## 8. 추가 (2026-10-11): 3몫 전환 + 소액 계좌 증거금 비율

사용자 결정: 3몫으로 전환, 운용 금액 42 USDT 미만, "최소 주문만 맞추는 만큼 종목당 증거금 % 를 올림". 정확한 금액은 아직 받지 못했다.
