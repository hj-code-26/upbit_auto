## 4. 규칙 (전부 설정값, 최적값 아님)

- 횡보: 마감된 15분봉 ADX(14) < 20 **그리고** ER(10) < 0.30
- 박스: 신호봉 **이전** 5분봉 24개(2h) 고저 H·L, 중앙 = (H+L)/2, ATR(14) 도 이전 봉까지
- 롱: 신호봉 저가 < L, 종가 > L, 종가 < 중앙 · 숏: 거울. 양쪽 동시면 무시
- 손절: 롱 = 신호봉 저가 − 0.25·ATR (숏 거울). 진입 당시 H·L·중앙·ATR·손절가 저장
- 진입 판단: 예상 진입가 = 신호봉 종가 ± 슬리피지. 비용 뺀 목표이익 > 0 **그리고** ≥ 1.0 × 비용 넣은 손절손실. 60분 안에 정산이 있으면 직전 정산률로 펀딩 비용(받는 쪽은 0) 반영
- 크기: 위험 0.2% / 계획 손절손실, 명목 ≤ 평가액 × 1, lot 내림, 3배 격리
- 청산
  - **A** 중앙 전량 지정가, 30분 미도달 시 시장가
  - **B** A + 15분 시점 최대 유리 이동 < 0.5 × |진입−손절| 이면 조기 종료
  - **C** B + 중앙에서 50% 익절 → 조건(1분봉 종가 ≥ 중앙 & EMA9 상승, 숏 거울) 검사 → 불충족 시 잔여 시장가, 충족 시 목표 = 반대편 경계 − 0.25·ATR, 추적 손절 = 최고 종가 − 1·ATR (단조 강화), 최초 체결부터 60분
  - **C′** C 와 같되 조건을 '익절 체결 분봉 마감 뒤' 에 검사
- **C 의 문언 해석 문제 (보고)**: "체결 시점에 확인 가능한 마감된 1분봉" = 체결 직전 봉이다. 지정가가 처음 중앙에 닿는 순간 체결되므로 그 직전 봉 종가는 거의 항상 중앙 **아래**(롱) → 조건은 사실상 늘 불충족 → C ≈ "절반 중앙 지정가 + 절반 중앙 부근 시장가". 그래서 C′ 를 같이 잰다. 둘 중 무엇을 C 로 볼지는 사용자 결정.
- 일손실: UTC 하루 시작 평가액 대비 −1% → 그날 신규 중단 · 대기 익절 취소 · 잔여 시장가 reduceOnly · 손절 주문은 flat 확인까지 유지

## 5. 백테스트 방법 (누수·착시 방지)

- 15분봉은 닫힘 시각 ≤ 5분봉 닫힘 시각인 것만. 박스·ATR shift(1). 테스트: 미래 데이터를 망가뜨려도 과거 신호 불변
- 진입 = 신호봉 마감 직후 1분봉 시가 + 슬리피지 (테이커). 진입 분봉에선 익절 안 봄
- 한 분봉 안 익절·손절 동시 → 손절. 갭이면 시가 체결
- 지정가 익절은 가격이 목표를 **넘어야** 체결 (닿기만 하면 미체결), 메이커 수수료
- 시간·조건 청산 = 판정 분봉 마감 다음 시가 시장가
- 펀딩 = 정산 시각에 남아 있던 비율 × 실측률(부호대로)
- 스트레스: 진입 판단·수량은 가정 비용(×1)으로 하고 **실현** 수수료·슬리피지만 ×1.5·×2 (비용 필터가 같이 엄격해져 결과가 좋아 보이는 착시 방지)
- 고정 진입 비교: 같은 진입 목록(60분 비중첩)에 A/B/C/C′ 적용, R = 계획 손절손실 단위, 롱·숏 분리
- 포트폴리오: 한 포지션, 복리, 계약 반올림, 일손실 정리선 (남은 여유 기준 근사 — `ponytail:` 주석)
- 구간: IS 2021-03~2023-12 · OOS 2024-01~2026-09. 고르는 값이 없으므로 OOS 는 안정성 확인
- 워크포워드: 유일한 선택지(청산 변형)를 직전 12개월 평균 R 로 고르고 다음 6개월에 적용

## 6. 판정 기준 (사전등록 — 결과 보기 전 고정, 이후 변경 금지)

변형별로, OOS(2024-01~) 고정 진입 · 실현 비용 ×1.5 에서:
1. 거래 ≥ 100
2. 평균 R > 0 이고 t ≥ 2.5 (변형 4개 다중비교 → Bonferroni 근사)
3. 롱·숏 **각각** 평균 R > 0 (양방향 가설이므로)
4. 실현 비용 ×2 에서도 평균 R > 0
5. 포트폴리오 OOS ×1.5: 최종 수익 > 0 이고 MDD ≥ −5% (0.2% 위험 기준 25R)
6. IS ×1.5 평균 R > 0 (부호 역전 없음)

전부 통과 → '모의운용 후보' (실계좌 아님). 하나라도 불합격 → 기각. 기각 뒤 파라미터 조정은 새 사전등록으로만.
시도 수: 이 파일이 1회. range_explore(216) 의 후속이라는 점을 해석에 반영할 것.
